# Mathematics of Machine Learning: From Scratch

A hands-on, chapter-by-chapter study accompanying Tivadar Danka's *Mathematics of Machine Learning* (Packt Publishing).

This repository bridges abstract mathematical theory with practical software engineering:
- **Theory & Proofs:** Synthesized conceptual notes, geometric interpretations, and theorem breakdowns.
- **Algorithms from Scratch:** Pure Python and vectorized NumPy implementations of key operations (Gram-Schmidt, LU decomposition, QR algorithm, numerical differentiation, gradient descent).
- **Benchmarking & Systems Profile:** Exploring memory layouts (C contiguous arrays vs. Python pointer collections), BLAS/LAPACK optimizations, and runtime trade-offs.

## Curriculum & Roadmap
1. **Part I: Linear Algebra** (Vectors, Norms, Transforms, LU, SVD, Graph Duality)
2. **Part II: Univariate Calculus** (Sequences, Differentiation, Optimization, Integration)
3. **Part III: Multivariable Calculus** (Jacobians, Hessians, Multivariable Gradient Descent)
4. **Part IV: Probability Theory** (Measure Spaces, Random Variables, Information Theory, MLE)
